# HackTheBox — Starting Point Tier 1 — Sequel

**Sequel** — одна из Tier 1 машин. В этой машине я буду работать с базой данных MariaDB и получать к ней доступ.

Для практических заданий я буду использовать свою Linux-машину и подключение к HTB через VPN.

---

# Подключение к HTB

Сначала мне нужно подключиться к VPN Hack The Box.

Для этого я скачиваю `.ovpn` файл из настроек подключения и запускаю OpenVPN:

```bash
sudo openvpn Learn.ovpn
```

После успешного подключения в терминале появляется:

```text
Initialization Sequence Completed
```

После этого я запускаю машину Sequel и получаю её IP-адрес.

IP-адрес машины буду обозначать как:

```text
10.129.184.201
```

---

# Enumeration

Первым делом я хочу посмотреть, какие порты открыты на машине.

Для этого запускаю Nmap:

```bash
nmap 10.129.184.201
```

В этом случае я хочу получить больше информации о найденных сервисах, поэтому использую:

```bash
sudo nmap -sC -sV 10.129.184.201
```

Ключ `-sC` запускает стандартные NSE-скрипты, а `-sV` пытается определить версии найденных сервисов.

Если стандартного сканирования недостаточно, можно просканировать все TCP-порты:

```bash
sudo nmap -p- 10.129.184.201
```

После сканирования я вижу открытый порт базы данных:

```text
3306/tcp
```

Порт **3306** используется MariaDB/MySQL.

Теперь я понимаю, что дальше нужно исследовать именно базу данных.

---

# MariaDB

MariaDB — это реляционная система управления базами данных, совместимая с MySQL.

Так как на машине открыт порт 3306, я пробую подключиться к базе данных с помощью клиента MySQL/MariaDB:

```bash
mysql -h 10.129.184.201 -u root
```

В некоторых системах клиент может называться `mariadb`:

```bash
mariadb -h 10.129.184.201 -u root
```

При подключении я вижу, что сервер позволяет подключиться пользователю `root`.

Если клиент выдаёт ошибку, связанную с SSL, можно использовать:

```bash
mysql -h 10.129.184.201 -u root --skip-ssl
```

# Получение доступа к базе

После подключения я попадаю в консоль MariaDB.

Проверяю, какие базы данных доступны:

```sql
SHOW DATABASES;
```

После этого выбираю интересующую базу.

Теперь можно посмотреть таблицы:

```sql
SHOW TABLES;
```

После нахождения таблицы смотрю её структуру:

```sql
DESCRIBE table;
```

или:

```sql
SHOW COLUMNS FROM table;
```

После этого я могу посмотреть содержимое таблицы:

```sql
SELECT * FROM table;
```

Таким образом, я получаю доступ к данным, которые находятся внутри базы.
